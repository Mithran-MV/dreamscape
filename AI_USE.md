# How AI was used

ETHGlobal asks every team to say where and how AI tools were used. This file is kept up to date during the event, file by file.

## The tool

One AI coding assistant, used in agent mode from the terminal. No other AI tools were used to write code, text or assets for this repo. The app's own AI features run on 0G Private Computer and are part of the product, not of how it was built.

## What the author does

- The idea, the product design, the user flow and every decision about what gets built.
- The architecture: what runs on 0G, what lives on Arkiv and what lives on ENS, and why.
- Directing the assistant through `SPEC.md` and prompts, reviewing every change, and deciding what to keep.
- Testing on real devices and real testnets, the demo and the video.

## What the assistant does

- Runs setup commands (scaffolding, dependency installs) and writes boilerplate.
- Drafts code from the spec and the author's instructions, which the author then reviews, tests and changes.
- Drafts documentation such as this file, `SPEC.md`, the README and the `/arkiv` files, which the author edits.

## Spec

`SPEC.md` is the spec the assistant works from. It was drafted with the assistant at the start of the event from the author's description of the idea.
