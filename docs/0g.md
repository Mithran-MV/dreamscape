# How Dreamscape uses 0G

Remove 0G and Dreamscape can no longer hear, read or paint a dream in private, keep it encrypted, or prove when it was kept. The dream is gone by breakfast.

## What runs on 0G Private Computer

Every call goes through `router-api.0g.ai`. The router picks the provider; the app never pins one, so the provider change after 0G's maintenance on Nov 6 needed no code change.

| Step | Model | Trust mode | What the model sees |
|---|---|---|---|
| Hear the voice note | `whisper-large-v3` | private (enclave), fails rather than falling back | the voice note |
| Read the dream: title, themes, feeling, scene | `0gm-1.0-35b-a3b` | private, encrypted end to end (`X-0G-E2EE: sealed`) | the dream's words |
| Paint the portrait | `z-image-turbo` | private, enclave verified | a scene description |
| Link sagas, write the comic script | `0gm-1.0-35b-a3b` | private | tags and the dream's words |
| Draw comic panels | `tencent/hy-image-3.5-preview` | standard | scene descriptions only, never dialogue |
| Animate the portrait | `bytedance/seedance-2.0` | verified when available, else standard | the painted portrait and a motion line |
| Paint the World Dream | `z-image-turbo` | private | shared themes only, never anyone's words |

**Rules the code keeps**
- **Sealed steps never fall back.** If no private provider is free, the step waits and retries, for up to about three hours. Code: `src/lib/server/zerog/router.ts` and `worker/index.ts`.
- **Video does fall back.** When Seedance left 0G's verified tier, the app moved to a standard provider. Video was never sealed: in either mode the vendor sees the portrait. Each clip records which kind made it.
- **The comic's words never go to an image model.** Panels come back with no text, and the app letters the page itself, so every word is the dreamer's own and nothing gets garbled.

## 0G Storage

The server encrypts each file with AES-256 under a key derived for that dreamer (HKDF over the server's master key) before it leaves, using the storage SDK's own encryption. Each file starts with a short check header, so a wrong key is caught instead of returning noise. The explorer shows files by sequence number, so the app's links go through `/api/storage/<root>`, which looks the number up on a storage node and redirects.

## Credits

- **Measured on real dreams.** A dream costs about one cent: $0.0012 for tagging plus $0.0088 for the painting, and $0.0007 more for a voice note. A comic costs about ten cents (four panels at $0.025). A 5-second moving portrait is about $0.35.
- **A daily budget.** The nightly run never plans past $1 of credit a dreamer spends in a day, and the moving portrait only uses credit the comic left.
- **Sign in with 0G.** The `/0g` page uses 0G's own sign-in, which 0G allows on `localhost:3000`. It shows the signed-in account's 0G Pay balance and how much was spent since sign-in.

## What we ran into

- **Reasoning tokens count against `max_tokens`.** At `reasoning_effort: "low"`, `0gm` spent 5,439 tokens thinking before a comic script and ran out of room. At `"minimal"` the same script took 422 tokens. The app now uses minimal reasoning for its short JSON tasks.
- **The private providers were offline** from about 11:20 pm IST on Nov 5 until 0G's maintenance moved them. The worker waited them out instead of falling back.
